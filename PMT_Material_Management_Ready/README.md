# PMT Material Management Android App

This is the Android WebView app for the PMT Material Management Google Apps Script web application.

The Apps Script URL is already configured in `MainActivity.kt`.

## Build online with GitHub Actions

1. Upload the contents of this project to the root of a GitHub repository.
2. Open **Actions**.
3. Select **Build PMT Material Management APK**.
4. Click **Run workflow**.
5. When the build finishes, download the artifact named `PMT_Material_Management`.

The artifact contains `app-debug.apk`.
